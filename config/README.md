# 引脚配置工具

直接用现代浏览器打开 `index.html`，无需服务器、安装依赖或网络连接。

1. 按实际开发板接线选择 PAW3805EK-CJV1 裸芯片的 NCS、SCLK、SDIO 三根线。
2. 必要时设置方向修正（先交换 X/Y，再反转）。
3. 下载 `PAW3805EKConfig.h`，放到 `src/include/` 替换默认配置，然后重新编译、手动烧录。

工具禁止重复引脚及当前工程占用的 PA9、PA12、PA13、PB22。GPIO 编号不是封装脚号；列表范围不能证明某一具体封装/开发板引出了该引脚。供电、去耦、镜片和焊接仍需按器件资料确认，不能用原霍尔 GPIO 直接给传感器供电。

本页只生成编译期配置，不烧录、不连接设备、不修改 BLE 运行参数，也不配置 CPI 或芯片电源。默认固件中的 `PAW3805EK_CONFIGURED=0` 不会操作传感器 GPIO；生成的有效配置将其设为 `1`。
